Slide 2: The Problem

The Broken State of Web2 Mood Tracking

  • Corporate Exploitation: User feelings are harvested for algorithmic outrage and ad profiling.
  • Fragility & Censorship: Centralized databases can censor, alter, or delete personal histories.
  • No Web3 Composability: On-chain communities lack lightweight social primitives to gauge morale.
Slide 3: The Solution

The MoodMark Protocol

  • On-Chain Attestation: 9 expressive moods recorded directly to MoodMark.sol.
  • Zero Server Infrastructure: State is verified and stored purely on-chain.
  • Universal Lookup: Instant real-time mood queries for any EVM wallet address.
Slide 4: Technical Architecture

Gas-Optimized EVM Engineering

  • Packed Storage: Enum (1 byte) + boolean (1 byte) in a single 32-byte EVM storage slot.
  • Custom Errors: InvalidMood() eliminates high revert string bytecode costs.
  • Next.js + Wagmi Client: Instant RPC connection and responsive dark theme UI.
